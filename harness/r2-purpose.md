# R2 — 목적

| # | 항목 | 결정 |
|---|---|---|
| Q1 | 매번 달라지는 것 (입력 변수) | 대상 화면 1개 — PRD 16장 핵심 화면 10개 중 하나 |
| Q2 | 사용자 | 나 혼자 (디자이너 1명) · 사람 승인자도 1명 |
| Q3 | 에이전트 범위 | 1~3단계(수집·분석·설계) + 7단계(검토)는 에이전트, 4~6단계(Figma 제작·협의·토큰/컴포넌트)는 사람 |
| Q4 | 완료 기준 | 아래 한 문장 |

## 입력 규칙

- 입력값은 PRD 16장 핵심 화면 목록에 있는 이름이어야 한다:
  홈 / 무료 학습자료 / 유료 멤버 자료실 / 스킬 라이브러리 / 미션 상세 / 제출 화면 / 내 학습 / 내 자산 / 자산 상세 / 운영자 검수 화면

## 완료 기준

> 대상 화면 1개에 대해 **화면 설계 문서 1개 + Figma 시안 JSON 1개**가 있고, 판정 스크립트 결과가 **`design.md` 위반 0건 · `story-service.md` 규칙 위반 0건**이며, **사람 승인 1회**가 기록되면 완료다.
